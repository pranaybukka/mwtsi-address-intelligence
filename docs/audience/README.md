# MWTSI Address Intelligence — audience documentation

Application baseline: v1.4.0 | Documentation revision: 1.1 | 7 November 2026

Start with the guide for your role:

- IT: technical architecture, Windows/local setup, deployment configuration, backup/recovery, upgrades, security gaps, testing and support runbook.
- Operations: quick start, intake-to-handoff SOP, Group and export scope, acceptance without required fixes, reconciliation, and the source/generated-field dictionary.
- ELT: executive briefing, evidence and limitations, proposed risk register, phased readiness roadmap, pilot metrics and decisions to assign.

Each guide is supplied as a PDF for reading, editable Word (.docx), and Markdown (.md). Operations also includes an editable CSV field dictionary.

These are initial working documents. They describe actual v1.4 behavior separately from proposed organizational roles, policies, targets and production-readiness work. Acceptance is not validation or payment approval. No production certification, enterprise identity control, Windows/browser test completion, operational ROI or committed rollout date is claimed.

The private download page distributes files; the operational application runs locally or on an IT-provided service. Keep the application version and documentation revision together when sharing. Do not include customer workbooks or database copies in a documentation handoff.

PDF headings and table contents were text-checked, all Word packages were opened programmatically, and representative PDF pages were visually inspected. Word pagination can vary by installed fonts and Office version; native Word/Windows rendering was not tested.
